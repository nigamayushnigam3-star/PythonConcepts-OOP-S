# PythonConcepts & OOP's

A beginner-friendly Python learning repository covering core Python concepts and Object-Oriented Programming (OOP) with hands-on examples and a mini project.

---

## 📁 Files

### `PythonConcept.py`
Covers Python **Data Structures** and core concepts:

| Topic | What's covered |
|---|---|
| **List** | Indexing, traversal, methods, practice questions |
| **Tuple** | Access, index/count methods, tuple unpacking |
| **Set** | Mutable/unordered nature, set methods, set operations (union, intersection, difference, symmetric difference) |
| **Dictionary** | CRUD operations, traversal, deep copy vs shallow copy |
| **Exception Handling** | try/except/else/finally, raise exception |
| **Misc Programs** | Gender greeting, string traversal, Hello World n times, natural numbers |

**Practice Questions included:**
- Print positive and negative elements of a list
- Find mean/average of a list
- Find greatest element and its index
- Find second largest element
- Check if list is sorted
- Merge two dictionaries
- Sum all values in a dictionary
- Count frequency of each element

---

### `oop's.py`
Covers **Object-Oriented Programming** concepts step by step:

- Class & Object basics
- Attributes and Methods
- `self` keyword
- `set_info()` and `display()` methods
- Passing parameters to methods
- Constructor / Initializer (`__init__`)
- Return types with type hints (`->int`, `->None`)

---

### `oop's_project.py`
**Mini Project — Movie Ticket Booking System**

A simple OOP-based movie ticket booking system with:
- `book_tickets(num_tickets)` — books tickets if seats are available, shows total price
- `show_status()` — displays movie name, available seats, and booked seats

```python
movie = Movie("Krish", 100, 399)
movie.show_status()
movie.book_tickets(30)
movie.show_status()
movie.book_tickets(70)
```
